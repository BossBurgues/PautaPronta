# Pauta Pronta

Uma ferramenta web leve para transformar temas em rascunhos de carrosséis prontos para revisão e publicação no LinkedIn e Instagram.
Gera slides estruturados (1080×1350), legendas com CTA e fontes de referência com custo zero de infraestrutura.
Construído com React, Cloudflare Workers e Gemini API.

Ver [PLANO_EXECUCAO.md](PLANO_EXECUCAO.md) para detalhes de arquitetura, fases e execução.
